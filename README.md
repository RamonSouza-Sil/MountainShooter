# Moutain Shooter
Jogo 2D estilo fliperama utilizando PyGames(Python).
![Menu Principal](https://github.com/RamonSouza-Sil/MountainShooter/blob/master/Assets/Menu%20Mountain%20Shooter.jpeg)




### Mecânicas
- Sobreviver as fases
- Matar o máximo de inimigos
- ir até a fase 3
- Controle Multiplayer
- Competição entre Jogadores
- Salvamento de Score (LiteSQL)

### Publico Alvo
Jogo projetado para pessoas que buscam desafios e High Score. Com uma gameplay rápida e podendo competir contra um segundo jogador para ver quem consegue o maior Score nas 3 fases.

### Gameplay 1 Player
O jogador controla uma nave espacial, com os botões A, W, S, D ele faz a nave ir para frente, trás, cima e baixo, tendo como objetivo desviar das naves inimigas e destrui-las com tiros apertando Alt.
![Tela um jogador](https://github.com/RamonSouza-Sil/MountainShooter/blob/master/Assets/Vers%C3%A3o%201%20player%20mountain%20shooter.jpeg)

### Gameplay 2 Players
Agora mais um jogador poderá ser adicionado ao jogo, utilizando os botões de seta para se movimentar e Ctrl para atirar da mesma maneira que o jogador 1.

![Tela Multiplayer](https://github.com/RamonSouza-Sil/MountainShooter/blob/master/Assets/Gameplay%20Multiplayer%20mountain%20shooter.jpeg)

### Score (Pontuação)
Ao fim das 3 fases, os jogadores poderão guardar sua pontuação máxima e salvar seus nicks em um banco de dados, sendo possivel visualizar as pontuações no menu principal do jogo.
![Menu Score](https://github.com/RamonSouza-Sil/MountainShooter/blob/master/Assets/Tela%20de%20Score%20mountain%20shooter.jpeg)

### PyGames 
[Pygame](https://www.pygame.org/news) é uma biblioteca do Python utilazada para criar jogos 2D, também utilizada para a criação de gráficos, simulações e expêriencias multimidia.


### Pré Requisitos
-Python 3
-Pygames
-Sqlite
-Numpy

### Como baixar?
Você precisa ter o Python instalado. Depois, instale o Pygame com:
```bash
pip install pygame
````
Depois você precisará instalar o Numpy da seguinte forma:
````bash
pip install numpy
````
Agora você pode rodar o projeto sem nenhum problema! Obrigado :)
